# 离线可视化样式

visualize.css 是本机 OpenAI 官方 visualize skill 1.0.49 随附的样式快照，用于让同一份 HTML 片段在笔记网页独立显示时仍有主题变量和控件样式。来源：/Users/vigor/.codex/plugins/cache/openai-bundled/visualize/1.0.49/skills/visualize/assets/visualize.css。

它随笔记图解导出内嵌，不依赖 Codex 安装路径、外网或运行中的聊天。不含原生宿主 API、图标库、CDN 与自动提示工具；教学片段应自行实现关键交互、使用直接标签、避免这些依赖。更新 skill 时应实际核对样式和交互后再更新快照，不运行时扫描其他插件。
