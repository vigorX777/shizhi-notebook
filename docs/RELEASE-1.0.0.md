# 拾知 v1.0.0 封板说明

版本：1.0.0；Git标签：v1.0.0；日期：2026-10-10。这是当前个人本机使用的功能基线；封板固定代码与依赖，不代表所有桌面验收已完成。后续修改另建codex/分支，发布新版本，不移动v1.0.0标签。

## 包含的功能

- Codex专用learning入口、中文导师模板、官方事件与thread/read、原始内容优先、持久队列和幂等整理。同题追问和沟通依据增量保存。
- 完整原图独立附件、最终Markdown与公式、Mermaid／SVG及独立HTML交互图持有。
- 科目实体笔记本首页、700ms开书、独立检索列表、原图缩略图、手动错题／掌握／心得／高亮、隐藏讲解和知识提示。
- 科目掌握统计、90天／全年足迹、4周复习；真实完整轮次与复习会话去重；北京时间统计。
- 版本化ZIP校验、包含全部附件的导出／恢复、人工记录保护、迁移安全备份。
- Windows原生目录、Codex npm／exe入口、跨平台Prisma调用、本机生成配置、Windows用户登录启动／后台管理与doctor。修正跨盘图解路径边界，避免将无关盘符视作学习目录。

不包含云同步、独立网页AI聊天、账号权限、自动出题、排行榜、等级或复习日程。固定local用户，服务仅监听本机；版本号与备份包格式号独立，备份仍是v1。

## 安装与运行基线

Node24.12+的24.x、Codex CLI 0.162.0协议基线、已登录的官方桌面。npm ci使用固定lock文件。Windows安装／迁移／交给Codex的指令见[WINDOWS.md](WINDOWS.md)。跨平台自动检查模板见[verify.yml](ci/verify.yml)；首次上传凭证缺workflow scope，模板未启用、没有Windows CI运行证据；仓库所有者补充权限后复制到.github/workflows/verify.yml启用。没有登录、没有桌面操作的CI只检验软件与正式协议握手。

## 验证记录

本机Mac：8项隔离测试和生产构建通过。已有真实双图与交互追问来源，正式库4笔记／5来源／4原图；首页、复习和备份检查见HOME、REAL-INTERACTIVE-FOLLOWUP与WORKBENCH。正式学习数据、私人诊断、生成配置、登录与凭证未进入Git；测试图片为tests/fixtures中的隔离验收素材。

新增验证覆盖Windows目录／CLI入口、含中文空格引号的命令、原图快照路径边界、跨盘图解拒绝、全新克隆配置和后台启动。Windows的真实桌面图片输入、原生可视化与会话互通仍需目标电脑按WINDOWS.md记录；不把路径模拟或CI当真人手势证据。

## 已知边界与后续项

- 原MVP还有独立题号拆分、默认主动图解、真实手势／中断恢复与完整离线场景的验收项，按ACCEPTANCE记录推进。
- 浏览器截图通道曾超时，当前UI有真实语义／几何和交互证据，未宣称像素级视觉验收。
- 当前依赖扫描存在已记录的上游公告：@fastify/static 8.x路径归一化／route guard、Prisma6工具链的deepmerge-ts／effect、KaTeX信任限制。修复建议涉及主版本变更或越过上游锁定范围，本次不强制升级或降级来改变封板基线。仅用于可信个人本机、固定127.0.0.1；不得拿本版直接部署为公网／多用户服务。后续依赖治理需要专项升级和回归。本轮扫描10项（5 low、5 high），可通过npm audit重查，数字可能随公告变化。
- 旧电脑的Codex会话不随Git或ZIP迁移；旧完整笔记可离线复习，新学习使用当前电脑的新会话。

## 维护与回滚

日常使用v1.0.0可保持detached checkout；开发新功能先git switch -c codex/<工作名称>。更新或回滚程序前导出学习ZIP并停止服务；checkout目标版本后npm ci、db:generate、setup、build，再启动并审核变化的hooks。程序回滚不保证旧代码读取新数据库；需要时用对应版本的备份恢复，不删除原数据冒充回滚。
