# 讲解、增量笔记与渲染

2026-10-10。用户提供的初中导师模板经调整后保存在 learning/导师模板.md；learning/AGENTS.md 规定每轮教学与归档的执行顺序。两份文件分别负责教学内容与归档协议，避免复制同一套规则。

## 现在的行为

- 单题先准备完整 Markdown，MCP 保存同一正文，再展示最终回答；官方结束收集以最终回答原文同步。准备正文不代替最终回答，缺最终回答仍未完成。
- 多题用唯一二级标题分段。每题内部使用三级标题；服务按 answerHeading 保存对应最终小节，缺失／重复标题不会显示完整。
- 同题追问关联 noteId，新轮次追加；重复调用只更新本轮来源，不替换原题。自动标签累积，人工标题、分类、标签、心得、错因和掌握状态不被自动修改。
- 知识点保存名称、总结、讨论信号和本轮依据；按不同来源轮次累计，不把重试算成反复讨论。没有学生明确表达不能标成已确认。摘要和追问都可被搜索，进入复习时一起隐藏。
- 原始 Source.answer 保留正式接口最终回答，不因图解归档而改变；显示正文中的指定本地产物链接被替换为独立持有的完整内容。

## 渲染支持与边界

Markdown 支持标题、强调、列表、引用、分隔线、GFM 表格／任务列表、代码块。KaTeX 支持 $ / $$ 与兼容转换的 \( \) / \[ \]，转换不改写代码。字体、CSS、JS、Mermaid 各类图解代码都随应用构建，不依赖 CDN。

可视化支持 Mermaid、SVG、learning-html 围栏，以及通过 visualizations 明确提交的本地 PNG/JPEG/GIF/WebP、SVG、独立 HTML。图片原始字节以完整 data URI 存储；文字产物保留完整 UTF-8 源码，备份随来源关联带走。原始用户上传图仍走独立附件 ID，不与讲解图解混淆。服务只读取指定路径，不扫描可视化目录。产物须属于学习目录或明确提供的 Codex 可视化目录；单文件最多 5 MB，文字图解最多 200 KB。

SVG 清理脚本／外部引用后作为图片展示，避免改变主页面；HTML 在没有同源权限的 sandbox 中运行，CSP 禁止网络及外部资源。允许内联交互程序。含外部资源的图解不能标为完整归档。没有源码／独立产物的原生临时可视化暂不能保留，导师应改用上述形式；不会把预览链接说成已保存。

目标是完整保存与正常阅读，不声称复刻 ChatGPT 的内部渲染器或所有原生组件。当前截图工具超时，不能声称已通过像素级视觉验收。
