# 科目笔记本与学习反馈

首页 `/#` 显示已有科目的笔记本、各科掌握统计、学习足迹和最近4周复习进展。笔记库独立在 `/#library`，科目列表使用 `/#subject/` 加编码后的科目名。数学、地理正式笔记已有对应封面；其他标准科目在出现笔记时使用各自本地SVG封面，自定义及待分类使用索引封面。没有重新加入大标题、顶部标题栏或口号。

点击封面播放700ms开书过渡；直接链接和浏览器前后退不播放。按钮支持Enter／空格，Escape可取消；系统减少动画设置直接进入。离开页面取消未完成动画，快速连点只导航一次。打开书本默认展示该科全部笔记，错题仍需人工筛选；从详情返回保留刚才的检索条件。

## 统计口径

- 科目、库存和掌握数量来自当前笔记和人工记录。未完成归档独立提示，不把问过的题自动算错题或已掌握。
- 新学习轮次完整归档且为学习消息时记录一次活动，按来源轮次ID去重；同轮多题不重复记学习次数。未完成、重复事件、非学习消息不增加次数。
- 进入隐藏讲解复习模式后，点击已掌握／需复习，同时保存状态并记录一次复习；同值也可记次，同一会话重复点击不重复计数。退出再进入生成新的会话。清除标记、普通编辑、浏览、搜索、刷新不记次。
- 时间以UTC保存，按北京时间划分日期；90天含今天，全年展示当前自然年，未来日期为空且不可点击。累计学习天数按有活动的不同日期计；一周从周一开始。
- 点阵点击或键盘聚焦展示当天归档／复习和相关笔记。方向键左右移动一周、上下移动一天，Home到范围起点，End到今天。全年在窄屏局部滚动。

旧数据库升级时，已完整来源标记为已处理，历史活动保持为空；旧未完成来源真正补齐后可记录当日活动。迁移标记文件使中途退出后可安全重跑setup。旧v1备份缺活动记录时导入空记录，旧的完整来源重读不会生成今日打卡；新包保留UTC活动、关联和去重状态。

## 服务接口

`GET /api/v1/dashboard?period=90d|year`：科目数量、掌握分布、汇总、逐日活动及四周复习次数。默认90d。

`POST /api/v1/notes/:id/reviews`：`{sessionId: UUID, mastery: "mastered" | "review"}`。状态及活动在同一数据库事务内写入；重复会话返回`recorded:false`，用于另一笔记的同一会话拒绝并保持状态不变。沿用本机地址、同源及网页写请求标识要求。


   脚本只允许47841测试实例；复习、重试、人工改科目均在隔离库操作，结果保存在`.local/home-ui-report.json`。可在同一实例重跑，断言以当前复习次数为基线；库存及初始科目状态会先恢复为fixture设定。
