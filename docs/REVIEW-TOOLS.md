# 复习提示与阅读标记

2026-10-10。对应用户的下拉箭头、手动掌握标记、复习知识点提示和划词高亮请求。

## 操作与保存

- 所有主网页下拉框使用同一16px箭头，右侧13px内缩、垂直居中，文本右侧42px留白。原生select仍保留选择与键盘行为；不改动归档图解内部的用户源码。
- 题目旁直接选择已掌握／需复习，或清除标记；已掌握使用绿色勾选状态，列表与详情一致。状态保存到人工字段，后续自动整理不覆盖。
- 隐藏讲解后可单独展开“知识点提示”，显示已提炼知识点名称和总结，缺总结时显示标签；不展开原讲解、追问解答或交互图解。再次进入复习会收起提示。
- 查看讲解时选中文字出现悬浮按钮，可设置或取消黄色高亮。正文、加粗等内联格式与相关追问都支持，跨段落／节点保存到同一引用；公式和交互图解保持独立渲染，不修改它们的内部DOM。Escape关闭工具，滚动时重新定位，选区离开视口时隐藏。
- 高亮使用笔记人工字段：来源段落键、引用原文、前后文和初始位置；追问以sourceId:itemKey隔离，不靠绝对页面坐标。正文更新后优先用上下文定位；同一句出现多次且不能确定时不猜位置。原记录仍保留，不改写归档Markdown。
- 自动刷新不重建相同高亮的DOM；人工保存时使旧查询失效，完成后重新计算筛选结果，避免旧查询暂时改回状态。
- 备份v1包含高亮；旧v1没有此字段时导入为空数组。已掌握、心得、标签等原有字段照常保存。升级前正式库安全备份 .local/pre-review-tools-backup.zip。
